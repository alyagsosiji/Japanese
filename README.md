# 天の川 · 은하수 일본어 단어장

은하수 밤하늘 테마의 일본어 기본 발음 & JLPT 단어장 웹사이트입니다.  
별도 빌드 도구 없이 정적 HTML/CSS/JavaScript로 동작하며, `index.html`을 직접 열거나 GitHub Pages로 바로 배포할 수 있습니다.

## 주요 기능

- **일본어 기본 발음 (104자 + 특수 발음)**
  - 청음 50음도 (46자) · 탁음 (20자) · 반탁음 (5자) · 요음 (33자)
  - 히라가나 / 가타가나 / 함께 보기 전환 및 발음 상세 설명
  - 촉음(`っ/ッ`), 장음(5단 모음 규칙·`ー`), 발음(`ん/ン` 동화), 외래어 확장 가타가나 정리
  - 원어민 음성(Web Speech API `ja-JP`) 듣기 및 가나 퀴즈
- **JLPT 단어장 (N5–N1 총 7,809단어)**
  - N5 (674) · N4 (630) · N3 (1,659) · N2 (1,778) · N1 (3,068)
  - 한자·히라가나·로마자·한국어 뜻 실시간 통합 검색, 품사/학습 상태 필터
  - 후리가나 표시 토글, 뜻 가리기(암기 모드), 예문 `<ruby>` 후리가나 및 한국어 번역
  - 별표(★) 저장 및 암기 완료 체크(`localStorage` 자동 저장, JSON 내보내기)
- **플래시카드 (별자리 암기)**
  - 3D 카드 뒤집기, 단축키(`Space`, `A`, `1`/`2`/`3`), 다시 보기/애매함 재출제
- **단어 퀴즈 (성운 테스트)**
  - 뜻 맞추기 / 한자 읽기 맞추기 / 듣고 맞추기, 오답 노트 및 일괄 별표 저장

## 실행 방법

```bash
python3 -m http.server 8000
```

또는 `index.html`을 브라우저에서 바로 열어 사용할 수 있습니다.
